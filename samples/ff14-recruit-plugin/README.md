# FF14 招募监控插件

监控 FF14 招募板关键词，发现**新出现**的招募时推送到灵动岛消息页（可选提示音）。

移植自同作者的 NapCat 插件 [`napcat-plugin-ff14-recruit`](../../../../Dev发布/napcat-plugin-ff14-recruit)
（原版运行在 NapCat/QQ 机器人里；这里改成灵动岛插件，推送到消息页而不是群消息）。

## 功能

- **关键词轮换轮询**：每次检查用一个关键词，避免对公开接口造成高频请求（接口有限流）
- **只监控国服**：接口不分区服，插件按 `worlds.json`（仅国服服务器）过滤，国际服招募丢弃并计入状态
- **快照差分**：每个关键词保存上次见到的招募 id，只推送新出现的
- **去重**：同一招募 10 分钟内不重复推送（接口的 id 会复用）
- **屏蔽名单**：`data/plugins/ff14-recruit/banlist.json`，支持 `玩家名` 或 `玩家名@服务器`，可带过期时间
- **屏蔽词**：描述里包含这些词的招募不推送
- **休息时段**：如 `02:00`~`06:30` 内不检查（支持跨天）
- **推送上限**：每次检查最多推送 N 条，避免一次刷屏
- **插件页**：监控状态、最近检查结果、下次检查、关键词；最近命中以**卡片**形式装在滚动容器里
  查看（类别/副本、发布服务器、玩家、装等、位置、剩余时间、描述全文），默认显示 10 条，
  可配置到 30 条（`max_hits`）
- **消息页只发摘要**：只推送「服务器名 + 招募内容」，其余字段留在插件页卡片里，避免消息页被长文本刷屏
- **提示音**：清单声明 `notify.sound`；**默认不响**，需用户在设置里打开该来源的开关

## 权限

```
network            访问招募板公开接口
messages.push      推送消息到消息页
notify.sound       允许该来源播放提示音（仍需用户开关）
ui.page            注册插件页（图标在主导航下方一行）
ui.settings        提供设置面板
```

## 数据布局

```
plugins/ff14-recruit/
├─ plugin.json
├─ Ff14RecruitPlugin.dll
└─ data/                       ← 静态表（随插件安装，只读）
   ├─ category_map.json        招募类别 id ↔ 名称/别名
   ├─ worlds.json              服务器 id ↔ 名称 + 大区
   ├─ ContentFinderCondition.csv  副本 id ↔ 名称（原项目为 GB2312，本仓库已转 UTF-8）
   └─ duty_override.csv        按类别覆盖副本名（GB2312 → UTF-8）

data/plugins/ff14-recruit/      ← 运行时数据（宿主创建）
├─ config.json                关键词、间隔、休息时段、屏蔽词…
├─ snapshot.json              每个关键词上次见到的招募 id
├─ banlist.json               屏蔽名单
└─ hits.json                  最近命中（最多 30 条）
```

改完 `duty_override.csv` 后可在插件设置里点「重载数据表」即时生效，不用重装。

## 配置项（插件独立 config.json）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `keywords` | 空 | 监控关键词，逗号分隔 |
| `monitor_enabled` | false | 是否启用监控 |
| `interval_sec` | 90 | 检查间隔（30~1800 秒） |
| `max_pages` | 2 | 每个关键词最多翻几页（每页 20 条） |
| `max_push` | 3 | 每次检查最多推送几条 |
| `max_hits` | 10 | 插件页最多显示几条命中卡片（5~30） |
| `rest_start` / `rest_end` | `02:00` / `06:30` | 休息时段，留空表示不设 |
| `block_keywords` | 空 | 描述屏蔽词，逗号分隔 |
| `api_base` | xivpf 接口 | 招募板接口地址 |

## 已知限制

- 新版本副本/服务器可能还没进静态表，会用 `副本#1018`、`未知服务器(4031)` 这样的编号兜底显示
- 公开接口对高频请求有限流：间隔不要低于 30 秒，`max_pages` 不要调太大
- 只做关键词搜索，不做时间/装等筛选（原版同样如此）
